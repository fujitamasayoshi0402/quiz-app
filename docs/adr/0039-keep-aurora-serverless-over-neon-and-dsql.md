# ADR-0039: DB は Aurora Serverless v2 を続ける。Neon・Aurora DSQL・Cloudflare への移行と比べた

- ステータス: Accepted
- 決定日: 2026-11-28

## 背景と課題

公開のあとの費用の実績は、dev と prod を合わせて月に約 31 ドルで、予算（月 30 ドル）の境目にある（[開発ガイドライン「コスト方針」](../development-guidelines.md#8-コスト方針)）。
そのうち DB（Aurora Serverless v2）が約 13 ドル（prod 約 6.6、dev の大半）を占める。
止まっている Aurora の復帰（15〜28 秒）は、出題の読み取りと「始める」をメモリに持って、ほとんど画面に出なくなった（[ADR-0038](0038-cache-play-reads-in-quiz-service-and-hide-db-resume.md)）。

費用を下げる案として、AWS をまるごと Cloudflare に移す案を考えた。見積もると、減る分の大半は DB から来る。そこで DB の選び方を比べ直した（DEV-235）。

## 判断基準

- 普段の操作、特に回数のいちばん多い回答が遅くならないこと
- 止まっている DB の復帰を、利用者が待たないこと
- 費用が下がること
- テナントの分離を、今と同じく DB の行レベルセキュリティで守れること（[ADR-0006](0006-row-level-multi-tenancy.md)）
- スキーマ・Flyway のマイグレーション・アプリのコードを、大きく書き直さずに済むこと
- 認証とバックアップの扱いが、今より弱くならないこと（[ADR-0014](0014-connect-to-aurora-with-iam-auth.md)）

## 計測: 操作ごとの DB との往復

DB を別のリージョンに置くと、DB との往復 1 回ごとに遅延が足される。prod と同じく読み取りをメモリに持つ設定で、2 回目の要求の往復を数えた
（`SqlStatementCounter.countRoundTrips`。SQL の本数にコミットの回数を足した目安。`DatabaseRoundTripReport` で出せる）。
東京とシンガポールの間の往復は、公開されている計測で約 65〜71 ms。68 ms として見積もった。

| 操作 | DB との往復 | シンガポールに置いたときに増える時間 |
| --- | --- | --- |
| 所属するテナント、カテゴリの一覧、「始める」（すべて） | 0（メモリから返す） | 0 |
| 出題の画面の「中断中」「今日の復習」「あとで見直す」 | 3〜4（並んで読む） | 約 0.3 秒 |
| 「始める」（未回答優先など。DB で始める） | 10 | 約 0.7 秒 |
| **回答（1 問）** | **12** | **約 0.8 秒** |
| 再開 | 8 | 約 0.5 秒 |
| 完了（結果） | 10 | 約 0.7 秒 |
| 履歴、ランキング | 3〜5 | 約 0.2〜0.3 秒 |

## 検討した選択肢

| 選択肢 | 普段の速さ | 復帰の待ち | 費用（月） | 移行の手間 |
| --- | --- | --- | --- | --- |
| **A. Aurora Serverless v2 を続ける（採用）** | 変わらない（同じリージョン） | 15〜28 秒。ADR-0038 で、ほとんど画面に出ない | 約 13 ドル | なし |
| B. Neon（シンガポール） | 回答 1 問ごとに約 0.8 秒遅くなる | 数百ミリ秒 | 無料プランに収まれば約 0 | 小さい（Postgres のまま） |
| C. Aurora DSQL（東京） | 変わらない | 止まらない | 無料枠（月 10 万 DPU、1 GB）に収まる見込み | 大きい（テナントの分離を作り直す） |
| D. AWS をまるごと Cloudflare に移す | DB の置き方による | DB の置き方による | API の実行は約 2 ドルしか減らない | とても大きい |

### A. Aurora Serverless v2 を続ける

- 今の構成のまま。行レベルセキュリティ、トリガー、Flyway、IAM 認証、自動バックアップがそのまま使える
- 復帰の待ちは、ADR-0038 で、ほとんど操作の裏に隠れた
- 費用は下がらない

### B. Neon（サーバーレスの Postgres）

- Postgres のままなので、スキーマ・行レベルセキュリティ・コードはほぼそのまま使える。止まった状態から数百ミリ秒で起きる
- **東京リージョンがない。** いちばん近いのはシンガポール（ap-southeast-1）で、上の計測のとおり回答が 1 問ごとに約 0.8 秒遅くなる
- IAM 認証と Data API でのロールの作成（ADR-0014）が使えず、パスワードの管理に戻る
- 無料プランは、戻せる期間が 6 時間、ストレージが 1 GB まで。DB が AWS の外に出るため、ネットワークとシークレットの扱いも変わる

### C. Aurora DSQL

- 東京にあり、一時停止がない。使った分だけの課金で、量は無料枠に収まる見込み（東京の単価は料金のページに載っていない）
- PostgreSQL との違いが、今のスキーマとコードにそのまま当たる
  - **行レベルセキュリティと、`set_config` / `current_setting` でのテナントの受け渡しが、文書に載っていない。** テナントの分離（ADR-0006）を、アプリで絞る形に作り直すことになる
  - トリガーがない。`updated_at` を付けるトリガー（9 つの表）をアプリに移す
  - 1 つのトランザクションに DDL は 1 文だけで、DML と混ぜられない。Flyway のマイグレーションを分け直す（データを写すマイグレーションもある）
  - 1 つのトランザクションで変えられる行は 3,000 行まで。クイズの一括取り込み（1 回 500 件、選択肢を含めると 3,000 行を超えうる）を分ける
  - ロックがなく、楽観的な同時実行の制御になる。`FOR UPDATE`（テナントの退会、招待の受け入れ）と、Outbox の `FOR UPDATE SKIP LOCKED` の前提が変わり、衝突（`40001`）での再試行を各所に入れる

### D. AWS をまるごと Cloudflare に移す

- Workers は JS/TS しか動かないため、Kotlin（Spring Boot）は Containers で動かす。Spring は起動に 46〜81 秒かかり止めておけないので、常時動かすと月に約 12 ドル（有料プランの 5 ドルを含む）で、今の ECS（パブリック IPv4 を含めて約 14 ドル）から約 2 ドルしか減らない
- Cloudflare には Postgres がなく（D1 は SQLite）、DB は B か C と同じ選択になる
- Terraform、デプロイ、認証（Cognito）、通知（EventBridge・Lambda・SQS）、下書きの生成（Bedrock）を作り直す

## 決定

**A を採る。DB は Aurora Serverless v2 を続ける。**

- B は費用が下がるが、いちばん多い操作の回答が毎回 0.8 秒ほど遅くなる。止まった DB の待ちは ADR-0038 でほとんど隠れたので、B の速さの利点は小さい
- C は速さと費用の両方で良いが、テナントの分離を DB からアプリに移すことになる。分離の守り方を弱めて得るのが、月に約 13 ドルでは見合わない
- D は、減る分の大半が DB から来るため、DB の選び方（B か C）の問題に戻る。そのうえ作り直しが最も大きい

## 結果

### 良い影響

- 構成を変えないため、テナントの分離・マイグレーション・認証・バックアップの前提がそのまま保たれる
- 操作ごとの DB との往復を数えられるようになった。DB の置き場所を変える案を、同じ物差しで比べ直せる

### 悪い影響・受け入れるリスク

- 費用は下がらず、予算の境目にあるまま。超えた月は予算の通知で気づく
- 起動の直後（デプロイ、dev の起動）と、回答・履歴などの DB を読む操作は、今どおり復帰を待つことがある

### 緩和策

- 予算を超える月が続いたら、DB 以外の費用（prod の夜間の停止など）から見直す（DEV-199）
- 回答の往復（12 回）を減らせば、B の遅れは小さくなる。B を見直すときは先にこれを行う

## 検証事項

- **見直す条件**: Neon に東京リージョンができたとき。Aurora DSQL が行レベルセキュリティとトリガーに対応したとき。回答の往復を 5 回ほどに減らせたとき
- B の遅れは、公開されている往復の時間からの見積もりで、Neon につないで測ってはいない。Neon の中継と TLS の分は含まない
- C の行レベルセキュリティと `set_config` は「文書に載っていない」ことまでしか確かめていない。見直すときは、試しのクラスタで確かめる
- C の東京の単価は、料金のページに載っていない（米国東部（オハイオ）は 100 万 DPU あたり 8 ドル）
