# クイズの書き方

デモのテナントと、自分で作ったテナントのクイズを書くときの決まり。どちらも同じ決まりで書く。
置き場所と流し込み方は [ADR-0034](adr/0034-keep-quiz-content-as-packs-and-load-through-api.md) にある。

## 1 問の形

| 部分 | 決まり |
| --- | --- |
| 問題文 | 1 つに決まる問い方にする。「正しいものはどれですか」「〜はどれですか」で終える。否定の問い（「誤っているものは」）は使わない |
| 選択肢 | 4 つ。正解は 1 つ。誤答は、知らなければ選びそうなもっともらしいものにする |
| 解説 | 正解の理由と、ほかの選択肢がなぜ違うか。最後に出典 |
| 図 | 解説を読むより早く分かるときだけ入れる。1 問に 1〜2 枚 |

### 問題文

- 何を答えればよいかを、問題文だけで分かるようにする。図を見ないと解けない問題は、問題文で「図の A〜D のうち」と書く
- 引っかけにしない。読み違いを誘う言い回しや、二重の否定を使わない
- 時とともに変わる事実（人口、記録、最新の版）は、いつの時点かを書く（「2025 年の時点で」）
- 長さはスマホの幅で 3 行までを目安にする

### 選択肢

- 長さと書き方をそろえる。正解だけが長い、具体的、という手がかりを作らない
- 「すべて正しい」「どれでもない」は使わない
- 誤答は、よくある思い違いから作る。でたらめな選択肢は、選ぶ理由がないので解説も生きない
- 数を問うときは、近い値を並べる（「7 日」なら「5・6・7・8 日」）
- 並び順は、数なら小さい順、それ以外は正解の位置が偏らないようにする

### 解説

- 1 行目で、正解を言い切る。続けて理由を書く
- ほかの選択肢がなぜ違うかを、1 つずつ短く書く。誤答を選んだ人が、何を取り違えたかに気づけるようにする
- 段落は短く。箇条書きや表を使う（Markdown。[ADR-0018](adr/0018-write-explanations-in-markdown-and-render-on-screen.md)）
- **出典の文章をそのまま写さない。** 自分のことばで書き直す。引用が要るときは、短く、かぎかっこで示し、出典を書く
- 出典は最後に「出典: [名前](URL)」の形で書く。公式の資料、辞書、教科書、百科事典など、たどれるものにする

## 図

- **白い背景**に描く。画面は図を白い面に出す。ダークモードでも同じ見え方になる
- 配色は次の 5 つに限る。意味を決めて使い、色だけで区別しない（形や文字も添える）

  | 用途 | 色 |
  | --- | --- |
  | 線、文字 | `#1f2937` |
  | 面（中立） | `#f3f4f6` |
  | 強調（見てほしいところ） | `#2563eb` |
  | 正しい、進む | `#16a34a` |
  | 誤り、止まる | `#dc2626` |

- **スマホの幅（360px）で読める**ようにする。図は画面の幅に縮んで出る。横 800px の図なら、文字は 18px 以上にする
- 1 枚に 1 つのことを描く。説明が 2 つあるなら、図を 2 枚に分ける
- 横長にしすぎない。縦横の比は 2:1 までを目安にする
- 代替テキストを必ず書く（`![世界地図。南アメリカ大陸の西側に印](figure:world-map)`）。図が出せないときと、読み上げで使う
- 写真や他人の図は、自分で撮ったものか、使ってよいことがはっきりしたもの（ライセンスと出典を解説に書く）だけを使う
- draw.io の原本（`.drawio`）を残す。図は変えられないので、直すときは原本から描き直して新しい図にする（[ADR-0020](adr/0020-reference-figures-from-explanations-and-add-images-and-pdfs.md)）

## カテゴリと難易度

- カテゴリは、見る人が「これを解きたい」と選べる単位にする。1 カテゴリに 6 問以上
- カテゴリの説明は 1 行。何が問われるかを書く
- 難易度は、カテゴリごとに体系を決める。カテゴリをまたいでそろえなくてよい

  | 例 | 難易度 |
  | --- | --- |
  | 一般教養 | やさしい / ふつう / むずかしい |
  | 資格に沿った技術 | 資格の区分（CLF / SAA など） |
  | 技術の分野 | 基礎 / 応用 / 実務 |

- 「むずかしい」は、知識の量ではなく、考える手順が多いものにする。細かすぎる暗記を問わない

## 公開する前に

- [ ] 事実を、出典で確かめた。時とともに変わる事実には、時点を書いた
- [ ] 正解は 1 つに決まる。ほかの選択肢が、解釈によって正解にならない
- [ ] 解説に、正解の理由と、ほかの選択肢が違う理由がある
- [ ] 出典の文章を写していない
- [ ] 図は白い背景で、360px の幅で文字が読める。代替テキストがある
- [ ] スマホの幅で、問題文・選択肢・解説・図を見て崩れていない
