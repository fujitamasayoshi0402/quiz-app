# まずは5問（DEV-224）

デモの出題画面の先頭から、設定なしで始める編集カテゴリ。
既存の出題APIで1つのカテゴリから出題するため、選んだ問題を `quizzes/starter.json` に収録する。
元のカテゴリの問題は残る。別のクイズとして登録され、回答履歴も別になる。

| 題材 | 元ファイル | 選んだ理由 |
| --- | --- | --- |
| じゃがりこのキリン | snacks-drinks.json | 身近なお菓子と言葉遊びで入りやすい |
| 任天堂の創業時の商品 | everyday-brands.json | 知っている会社の意外なルーツ |
| 初の長編フルCG映画 | movies-entertainment.json | 有名な作品から選べる |
| ウィルキンソンの誕生国 | snacks-drinks.json | 見た目の印象と答えの意外性 |
| トトロの同時上映作品 | movies-entertainment.json | 遊んだあと誰かに話しやすい |

先の3問を「やさしい」、後の2問を「ふつう」とし、登録順で出す。
画面は `demo` テナントに公開済みの「まずは5問」がちょうど5問あるときだけ入口を出す。
入口を出したときは、カテゴリの一覧から「まずは5問」を外す（DEV-237）。入口が出ないときは、一覧に残る。
アプリ（`apps/mobile`）には入口がないため、一覧に残したままにする。
名前を変える場合は `demo-starter-card.tsx` の `findDemoStarter` も合わせて変更する。入口の判定と、一覧から外す処理の両方がこれを使う。
元問題の誤りを修正するときは、ここに収録した同じ問題も修正する。

反映時は `tools/content/load.ts content/demo --profile <環境> --tenant demo --dry-run` で差分を確認し、
同じコマンドから `--dry-run` を外して追加する。画面のリリース前にパックを投入できる。
この機能の実装時点では、本番への追加投入・画面のリリースは行っていない。
